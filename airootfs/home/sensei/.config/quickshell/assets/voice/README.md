# 아로나 음성 대본 (아로나 63개 + 프라나 63개)

이 폴더의 wav 는 학습한 목소리(GPT-SoVITS)로 **자동으로 만든 것**이다. 손으로 녹음할 필요 없다.

- 대사를 고치면: `~/.config/quickshell/Arona.qml` 의 `aronaLines` / `planaLines` 를 고치고, 그 이름의 wav 를 지운 뒤
  `bash ~/shittim-os/tools/voice-build.sh [arona|plana]` (없는 것만 만들고, 받아써서 대본과 다르면 다시 만든다).
- 이름 끝이 -1, -2 … 인 대사는 같은 상황에서 하나를 골라 말한다. 없는 파일은 그때그때 합성해서 읽는다(몇 초 늦다).
- 표 밖의 말(Gemini 답변)은 `shittim-voiced` 가 즉석에서 합성한다. 자세한 것은 `~/shittim-os/CLAUDE.md` "목소리".
