# 아로나 음성 대본

아래 대사를 하나씩 녹음(합성)해서 **파일 이름 그대로** wav로 저장한 뒤 노트북의 이 폴더에 넣으면 됩니다.

    ~/.config/quickshell/assets/voice/arona/

- 형식: wav (모노/스테레오, 샘플레이트 아무거나). 앞뒤 무음은 짧게.
- 없는 파일은 그냥 소리 없이 넘어가므로 일부만 넣어도 됩니다.
- 프라나 목소리도 만들면 같은 이름으로 `assets/voice/plana/` 에 넣습니다 (성격을 프라나로 바꾸면 그쪽을 틉니다).
- 대사를 바꾸고 싶으면 `~/.config/quickshell/Arona.qml` 의 `lines` 표에서 글을 고치고 같은 이름으로 다시 녹음합니다.

| 파일 이름 | 언제 | 대사 |
|---|---|---|
| `greet-morning.wav` | 인사 (6~11시) | 좋은 아침이에요, 선생님! 오늘도 같이 힘내요! |
| `greet-noon.wav` | 인사 (11~14시) | 점심은 드셨어요? 아로나는 딸기우유가 좋아요! |
| `greet-afternoon.wav` | 인사 (14~18시) | 오후도 화이팅이에요, 선생님! |
| `greet-evening.wav` | 인사 (18~23시) | 오늘 하루도 수고 많으셨어요, 선생님. |
| `greet-night.wav` | 인사 (23~6시) | 선생님, 벌써 이렇게 늦었어요… 이제 주무셔야죠! |
| `pat-1.wav` | 머리 쓰다듬기 | 에헤헤… 선생님 손 따뜻해요. |
| `pat-2.wav` | 머리 쓰다듬기 | 앗, 머리 망가져요~! |
| `pat-3.wav` | 머리 쓰다듬기 | 더 쓰다듬어 주셔도 돼요! |
| `not-ready.wav` | 독에서 아직 없는 기능을 눌렀을 때 | 그 기능은 아직 준비 중이에요. 조금만 기다려 주세요! |
| `err-nokey.wav` | API 키 없이 말을 걸었을 때 | 아직 Gemini API 키가 없어요. 설정 → 아로나에서 키를 넣어 주세요! |
| `err-offline.wav` | 인터넷 끊김 | 인터넷에 연결되지 않은 것 같아요… 연결을 확인해 주세요. |
| `err-badkey.wav` | API 키 틀림 | API 키가 올바르지 않아요. 설정 → 아로나에서 다시 확인해 주세요. |
| `err-quota.wav` | Gemini 무료 한도 초과 | 무료 한도를 넘었어요. 잠시 뒤에 다시 불러 주세요. |
| `err-busy.wav` | 구글 서버 지연 | 구글 서버가 지금 많이 붐벼요… 잠시 후 다시 물어봐 주세요. |
| `err-toolong.wav` | 답이 잘렸을 때 | 대답이 너무 길어서 잘렸어요. 질문을 나눠 주세요. |
| `err-empty.wav` | 답이 비었을 때 | 대답이 비어 있어요. 다시 물어봐 주세요. |
| `err-filebig.wav` | 첨부 파일이 너무 클 때 | 파일이 너무 커요. 모두 합쳐 15MB까지만 받을 수 있어요. |
| `err-fileread.wav` | 첨부 파일을 못 읽을 때 | 파일을 읽지 못했어요. |
