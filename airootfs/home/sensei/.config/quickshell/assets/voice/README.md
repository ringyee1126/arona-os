# 아로나 음성 대본 (전체 62개)

대사를 하나씩 녹음(합성)해서 **파일 이름 그대로** wav로 저장한 뒤 노트북의 이 폴더에 넣으면 됩니다.

    ~/.config/quickshell/assets/voice/arona/

- 형식: wav (모노/스테레오, 샘플레이트 아무거나). 앞뒤 무음은 짧게.
- 없는 파일은 소리 없이 넘어가므로 일부만 넣어도 됩니다.
- 이름 끝이 -1, -2 … 인 대사는 같은 상황에서 하나를 골라 말합니다.
- 프라나 목소리는 같은 이름으로 `assets/voice/plana/` 에 넣습니다 (성격이 프라나일 때 재생).
- 대사를 바꾸려면 `~/.config/quickshell/Arona.qml` 의 `lines` 표에서 글을 고치고 같은 이름으로 다시 녹음합니다.
